# UHC World Gen Datapack

This datapack tweaks Minecraft world generation for a better UHC game.

It's also intended to be a template for anyone who wants to customize their world generation, because the datapack format is definitely tricky.

## Features

- No oceans (large-ish rivers still generate)
- Increased frequency of small caves
- Less extreme mountains and hills
- World bottom moved to -32 instead of -64

Coming soon:

- Ore generation customization

See [`FEATURES.md`](./FEATURES.md) for a full list of features and how to customize them.
